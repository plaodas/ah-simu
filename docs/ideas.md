# 冬季電照シミュレーション

## 背景

現在は夏季の被覆のみをモデル化している。

## 仮説

夜間電照を導入すると、

- 電照コスト
- 暖房コスト
- 到花時期

のトレードオフが発生する。

予測制御は電照時間を最適化し、
閾値制御よりコストを抑えられる可能性がある。

## 成功条件

- 電照モデルを追加
- 電照量を指標として可視化
- 閾値制御との比較
